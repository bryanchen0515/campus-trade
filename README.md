## 📖 專題核心精神與設計動機
在大學校園中，每逢開學與學期末，大量學長姐的專業教科書（如微積分、設計概論）、設計系昂貴的手繪材料（COPIC 麥克筆、雕塑工具）、宿舍生活家電（小冰箱、風扇）與代步腳踏車往往面臨無處存放或丟棄的浪費。而新進學弟妹卻需花費高昂原價重新購買。

「**CampusTrade 校園二手市集**」結合商業設計系的視覺體驗與前端現代化架構，以**校內安全面交**為核心概念，免除校外網購的高額運費與詐騙風險，打造一個安全、高質感、且具備真實資料 CRUD 管理與檢舉審查機制的二手循環平台。

## 🛠️ 技術架構
* **前端框架**：純標準 Web 現代架構 (HTML5, Tailwind CSS, Vanilla Modern ES6)
* **狀態管理與資料持久化**：CampusTrade Reactive State Engine + 瀏覽器 LocalStorage Sync
* **部署平台**：Vercel / GitHub Pages (靜態 CDN 極速託管)

---

## 🚀 本地執行方式
此專案無須繁瑣的 Node.js 編譯流程，可直接以任何瀏覽器開啟：
1. 進入本專案資料夾 `campus-trade`
2. 直接以滑鼠雙擊 `index.html` 即可在 Chrome / Edge 中完整操作所有功能！
3. 或使用任何本地伺服器：
   ```bash
   # Python (若有安裝)
   python -m http.server 3000
   ```

## 🌐 部署至 Vercel 步驟指南
1. 將專案上傳至個人的 GitHub Public Repository（例如 `campus-trade`）
2. 開啟 [Vercel 官方網站](https://vercel.com/)，以 GitHub 帳號登入
3. 點選 **Add New Project**，匯入 `campus-trade` 專案庫
4. Framework Preset 選擇 **Other**，Build Command 保留空白，點擊 **Deploy**
5. 約 10 秒內即可獲得專屬公開網址（例如 `https://campus-trade-cd20.vercel.app`）！
